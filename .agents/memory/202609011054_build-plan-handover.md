# Build plan handover

The plan now starts by establishing a small mapping-agnostic package structure and then migrates tested behaviour from `sssom-rosetta`.

The initial scope covers mapping, ontology, vocabulary, Maplib graph construction, validation, open outputs, and later registry differences.

FHIR-to-OMOP runtime work, SQL on FHIR, a runtime package, a UI, and Ariadne integration are deferred.

ADRs 0001 through 0005 were removed at the developer's request to avoid blocking implementation with premature decisions.
